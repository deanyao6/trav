# T-222 — Paraphrase exclusion and expense wordings

**Verdict:** r1 CHANGES_REQUESTED (3 major), r2 **APPROVE** (3 minor).
**Commits:** 8da15fa (build), d27b2ee (r1 fixes), Orchestrator follow-up (r2 minors 2 and 3).

## What shipped
- "the others" plus an absence clause ("walked", "left early", "didn't come") means the named people are the whole split, but only when the list includes the sender and any member payer. Anything else about "the others" asks.
- "not including / not counting / leaving out X" are except lists. A stated headcount that disagrees with the except list asks. A whole-group count ("all six of us except bea") drops the named people; the reviewer judged that acceptable.
- "them" right after a buying verb is the thing bought. In a split list it resolves only to one joined run of names; otherwise it asks. "everyone except him/her/them" resolves only to a name given before the except phrase.
- "all six" / "all 6" is a headcount only before a people word or standing alone, and it must match the roster or Trav asks.
- `tiers/suggest.ts`: a message is a stated payment (not a suggestion ask) only when it has no '?', a written amount, and a payment shape ("i got the bill…", "<thing> came to €x").
